# VIRAL ENGINE PROTOCOL

The `viral_engine` is a "summonable" mode designed for maximum reach and scroll-stopping impact. It is distinct from the standard brand-building production pipeline.

## CORE PATTERNS (THE 6 PILLARS)

1. **The 1.8s Lock (Motion Hook):**
   - NO static frames, title cards, or slow establishing shots.
   - MUST start with immediate camera motion: push-in, tracking shot, subject entry, or collision.
2. **The 2.3s Rhythm (Cut Pacing):**
   - Edits must follow a rhythmic pulse.
   - Average cut interval is 2.3 seconds.
   - Prompts must be structured as time-stamped sequences to ensure pacing.
3. **Single Emotional Register:**
   - Pick ONE emotion (e.g., Awe, Curiosity, Tension, Humor) and hold it for the entire clip.
   - Mixing emotions creates cognitive friction and reduces shareability.
4. **One Dominant Element per Frame:**
   - High visual clarity. One subject/action per shot to prevent viewer disengagement.
5. **Visual Payoff Loop:**
   - Every cut must provide a micro-reward or a new piece of information that justifies the next cut.
6. **The "Thumb-Stop" Contrast:**
   - Use high-contrast lighting or sudden color shifts in the first 1.8s to trigger biological attention.

## OPERATIONAL MODES

### MODE: [STANDARD] (Default)
- Focus: Brand consistency, character lore, cinematic atmosphere.
- Pacing: Variable/Narrative.
- Goal: Long-term engagement and world-building.

### MODE: [VIRAL] (Summoned)
- Focus: Pattern engineering, attention hacking.
- Pacing: Strict 2.3s rhythmic pulse.
- Goal: Maximum reach, high view counts, trend hijacking.

## USAGE WORKFLOW

1. **Input:** `[Subject] + [Viral Mode Trigger]` (e.g., "Elara Vance + Viral Mode: Cybernetic Eye Reveal")
2. **Briefing:** The system generates a `viral_brief.md` containing the Emotional Register and Hook Type.
3. **Prompting:** Agents use the `[MODE: VIRAL]` flag to apply strict structural constraints.
4. **Validation:** Output is checked against the 1.8s/2.3s rules before final generation.
