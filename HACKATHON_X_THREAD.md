# Forge NPS — Final X Thread for Hermes Agent Creative Hackathon

Event: Hermes Agent Creative Hackathon  
Tags to include where space allows: `@NousResearch` `@Kimi_Moonshot`

---

## Tweet 1/12 — Hook

```
I’m entering Forge NPS in the Hermes Agent Creative Hackathon.

It is not another AI image generator.

It is a creative production system where:
• Kimi plans and critiques
• Hermes runs the pipeline
• Spark renders
• Vision audits
• Memory learns

Every shot, accounted for. 🧵
```

---

## Tweet 2/12 — Problem

```
Most AI creative tools are black boxes.

Prompt in. Asset out. Maybe it works.

But production needs:
• a plan
• a quality gate
• a paper trail
• retry lineage
• memory of what failed

Forge treats creative AI like a real production pipeline, not a slot machine.
```

---

## Tweet 3/12 — Architecture

```
Forge NPS assigns explicit jobs.

Kimi creates a structured shot plan.
Kimi critiques the plan before render.
Hermes compiles workflow-aware prompts.
Spark / ComfyUI renders.
Vision audits.
Memory records the full event trail.

No hidden production fallback. No mystery handoff.
```

---

## Tweet 4/12 — Kimi Moonshot

```
Kimi is not used as a one-shot caption writer.

In Forge, Kimi does high-leverage director work:
• brief decomposition
• structured shot planning
• coverage critique
• risk scoring
• revision when critique fails

Bad plans get caught before GPU time gets burned.
```

---

## Tweet 5/12 — Hermes Agent

```
Hermes is the pipeline brain.

It handles:
• campaign intake
• memory/context retrieval
• skill selection
• prompt compilation
• remediation orchestration
• canonical memory writes

FastAPI routes stay thin. Hermes owns the production logic.
```

---

## Tweet 6/12 — Skills Library

```
Forge ships a 155-skill Hermes library:

• 14 closed-loop protocols
• 13 Spark / ComfyUI ops skills
• 15 style specialists
• 16 camera skills
• 13 lighting / color skills
• diagnostics
• FLUX.2 + LTX 2.3
• sound, VFX, verticals

It behaves like a virtual agency.
```

---

## Tweet 7/12 — Virtual Agency

```
Those skills are not decoration.

Every shot records `skills_used`, so I can see which expertise fired:

Cyberpunk color science.
Ghibli background language.
FLUX.2 product photography.
LTX 2.3 motion prompting.
Audit remediation.
Brand continuity.

The agent has departments.
```

---

## Tweet 8/12 — Memory

```
Memory is not chat history.

Forge records:
• campaign events
• render attempts
• audit scores
• failures
• remediations
• retry relationships

Then /api/memory/health checks the system for missing audits, orphan remediations, and unknown event types.
```

---

## Tweet 9/12 — Failure Handling

```
Failure is a first-class object in Forge.

A failed shot can be:
• re-audited
• remediated
• re-rendered
• linked back with `retry_of`

So the UI can show the full family tree:

original → failure → fix → retry → final audit
```

---

## Tweet 10/12 — What Judges Can Inspect

```
Click a shot and you can inspect:

• Kimi visual brief and rationale
• Kimi critique result
• Hermes compiled prompt
• negative prompt
• workflow profile
• skills used
• Spark prompt id / seed / path
• audit status and score
• retry lineage

The evidence is built into the app.
```
