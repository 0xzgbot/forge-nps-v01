# Forge NPS — Neural Production Studio

> **Winner of the Forge x NVIDIA Hackathon — May 2026**

An autonomous AI filmmaking pipeline that doesn't just generate shots — it *learns* from every mistake it makes. Feed Forge NPS a script and a world bible, and it produces a structured shot list, dispatches renders, audits them for consistency, repairs failures automatically, and remembers what it learned so the same error never happens twice.

The star of the show is **Hermes** — a self-learning memory agent with Karpathy-style explicit memory architecture that turns raw production outcomes into durable, reusable knowledge.

---

## 🌟 Star Feature: Hermes Self-Learning Memory Agent

Hermes is the brain of Forge NPS. It sits between the director and the renderer, observing every decision and outcome.

**Memory Architecture**
- **Episodic Memory** — Immutable log of every generation attempt, audit, and outcome.
- **Semantic Memory** — Distilled rules and insights generated by the Memory Consolidator.
- **Consolidator** — A "dream" process that transforms episodes into knowledge after each session.

**How it works**
1. **Query before act** — Before dispatching a shot, Hermes searches memory: "Have I seen something like this before?"
2. **Augment** — If a past fix or rule applies, Hermes injects it into the prompt automatically.
3. **Record** — Every outcome (success or failure) is logged with full context.
4. **Consolidate** — After a session, raw episodes are distilled into semantic rules with confidence scores.

**Teach Mode** — A controlled demo endpoint (`POST /api/hermes/teach`) that injects deliberate errors, records the failure and fix, triggers consolidation, and returns a before/after trace with the newly born insight. Perfect for live demos.

## 🎛️ 8-Tab Live Dashboard

A real-time FastAPI dashboard serves as the mission control for the entire pipeline.

| Tab | Purpose |
|-----|---------|
| **Home** | Live stats, recent renders, Spark queue monitor, quick actions |
| **Characters** | Character DNA editor, anchor consistency scores, variation gallery |
| **Script** | Shot list with expandable detail panels, audit history, prompt previews |
| **Products** | Product anchor management, generation banks (angle, material, lighting, context) |
| **Renders** | Batch dispatch UI, live queue monitor, render grid with status |
| **Memory** | Hermes Memory Core — Cytoscape.js graph, semantic insights, event timeline |
| **Models** | **Local ↔ API toggle** — switch between LM Studio and Kimi/NIM backends |
| **Settings** | Runtime configuration, restart controls |

The dashboard streams live updates via WebSocket — shot progress, reasoning traces, Hermes decision events, and Spark queue state.

**Models Page (Local/API Toggle)**  
One-click switching between local inference (LM Studio) and cloud APIs (Kimi K2.6 / NVIDIA NIM). Hermes routes all inference through the selected backend. Includes connection health checks and model discovery for both backends.

## 🎯 Consistency Scorer

A pixel-level consistency engine that scores any render against its character or product anchor image.

- **Histogram correlation** per RGB channel (0–100 scale)
- **Automatic pass/fail** threshold at 70%
- **Episodic logging** — every score is recorded in Hermes memory for trend analysis
- Accessible via `POST /api/consistency/score` or integrated into the batch pipeline

## 🚀 Quick Start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Configure environment
cp .env.template .env
# Edit .env and set:
#   KIMI_API_KEY=your_real_key_here
#   COMFYUI_PRIMARY=http://your-comfyui-ip:8188

# 3. Run the mock demo (no API keys needed)
python3 demo.py --mock

# 4. Run the memory-learning showcase
python3 demo.py --memory-demo

# 5. Run with injected failure to see remediation live
python3 demo.py --mock --mock-failure

# 6. Run with real APIs (requires keys + ComfyUI)
python3 demo.py --script scripts/demo/pilot_script.md

# 7. Launch the live dashboard
python3 dashboard/forge_dashboard.py
# → Open http://localhost:7000
```

## ⚙️ LM Studio Integration

Forge NPS supports **local inference via LM Studio** as a first-class backend:

- OpenAI-compatible API client (no heavy dependencies — uses `urllib`)
- Chat completions + embeddings support
- Configurable host via `LMSTUDIO_HOST` env var
- One-click toggle in the dashboard Models tab
- Automatic fallback when cloud APIs are rate-limited or unavailable

Set it up:
```bash
# .env
LMSTUDIO_HOST=http://localhost:1234
LMSTUDIO_CHAT_MODEL=your-gguf-model
LMSTUDIO_EMBED_MODEL=your-embedding-model
```
