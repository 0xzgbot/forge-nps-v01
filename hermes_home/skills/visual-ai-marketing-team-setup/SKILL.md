# Visual AI Marketing Team Setup

## Overview
This skill outlines the complete process for creating and organizing a team of specialized AI agents to handle visual marketing content creation autonomously.

## Prerequisites
- Access to Hermes Agent with skill management capabilities
- Knowledge of the specific roles needed in your marketing workflow

## Key Principles
1. **Specialization**: Each agent focuses on its domain while maintaining brand consistency across all stages.
2. **Integration**: Agents work seamlessly through structured handoffs and shared knowledge bases.
3. **Quality Control**: A rigorous QA process ensures only premium content is delivered.
4. **Continuous Improvement**: Daily self-improvement loops drive ongoing optimization.

## Step-by-Step Setup Process

### 1. Define the Team Structure
- Identify the specialized roles needed for your marketing workflow
- Create a clear hierarchy of agents with defined responsibilities
- Ensure each agent has a unique name and purpose

### 2. Create Individual Agent Skills
- Develop detailed SKILL.md files for each agent
- Include mission statements, core rules, daily improvement loops, and output formats
- Use consistent YAML frontmatter across all skills

### 3. Organize the Team Directory
- Create a main team directory (e.g., visual-ai-marketing-team)
- Place individual agent folders within this directory
- Ensure proper file organization for easy access and maintenance

### 4. Integrate Skills and Dependencies
- Identify overlapping capabilities between agents
- Consolidate redundant skills to eliminate redundancy
- Update references to ensure proper functionality

### 5. Create Comprehensive Documentation
- Develop a central team documentation file (TEAM_DOCUMENTATION.md)
- Create individual agent documentation files (MEMBER_DOCUMENTATION.md)
- Ensure all documentation is properly organized and accessible

### 6. Test the Workflow
- Run end-to-end tests to verify agents work together seamlessly
- Check handoffs between agents for proper data flow
- Validate that quality standards are met at each stage

## Best Practices
- **Consistent Naming**: Use a consistent naming convention across all skills and directories
- **Clear Documentation**: Ensure all documentation is comprehensive and easy to understand
- **Regular Maintenance**: Schedule regular reviews of the team structure and processes
- **Continuous Improvement**: Encourage agents to share insights and improvements

## Troubleshooting Common Issues
1. **Skill Creation Failures**:
   - Check for missing YAML frontmatter fields (name, description)
   - Ensure proper formatting and indentation
   - Verify all required fields are present

2. **Directory Organization Problems**:
   - Use terminal commands to move directories safely
   - Verify changes with ls command
   - Ensure file paths are correct

3. **Agent Integration Issues**:
   - Check for missing or incorrect references between agents
   - Validate that handoffs use proper JSON format
   - Test individual agent functionality before full integration

## Example Use Case
To set up a new Visual AI Marketing Team:
1. Define the team structure with 8 specialized agents
2. Create SKILL.md files for each agent with detailed specifications
3. Organize all skills in a visual-ai-marketing-team directory
4. Create comprehensive documentation for both the team and individual agents
5. Test the workflow end-to-end to ensure proper functionality
6. Schedule regular reviews to maintain optimal performance
