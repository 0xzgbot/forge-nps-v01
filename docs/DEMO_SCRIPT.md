# Forge — 60-Second Twitter Demo Video
**Target Duration:** 60 Seconds (Twitter sweet spot)  
**Format:** 9:16 vertical OR 16:9 horizontal  
**Tone:** Warm, energetic, confident — "Your creative director just got a memory upgrade"  
**Audio:** Voiceover + background music + burned-in captions

---

**Visual:** Rapid montage of a complete campaign in one flow:
1. Three Instagram posts, same brand, perfect consistency

## Production Notes

### Required Captures
1. **Campaign Montage** — 4+ consistent brand assets (Instagram, TikTok, TV, product)
2. **Model Stack Cards** — Kimi 2.6, FLUX2, Z-Image, LTX, WAN
3. **Dashboard Walkthrough** — Brief input, campaign generation, model toggle
4. **Teach Mode Sequence** — Break → fail → learn → fix → pass
5. **Export Brain** — Download + JSON preview

### Editing Checklist
- [ ] **Burn captions** — most Twitter videos are watched silent
- [ ] **Hook in 3 seconds** — first frame must be beautiful output
- [ ] **Show Kimi** — at least one scene proves Kimi 2.6 / NVIDIA NIM usage
- [ ] **Arc is clear** — problem → solution → proof → takeaway
- [ ] **Under 60 seconds** — Twitter engagement drops after 60s
- [ ] **End with CTA** — logo + tagline, memorable

### Music Suggestions
- Upbeat, playful electronic for the hook
- Build to confident resolve for the payoff
- No lyrics — voiceover must be crystal clear
