## Production Notes

### Required Captures
1. **Campaign Montage** — 4+ consistent brand assets (Instagram, TikTok, TV, product)
2. **Model Stack Cards** — Kimi/latest Director or LM Studio Director, FLUX2, Z-Image, LTX, WAN
3. **Dashboard Walkthrough** — Brief input, campaign generation, model toggle
4. **Script Studio One-Click** — Type a short story prompt, click **Generate Videos**, show Jobs progressing package → coverage → storyboard → frames → videos
5. **Script Studio Outputs** — Show generated 1080p start frames and completed clips inside Script Studio Videos
6. **Teach Mode Sequence** — Break → fail → learn → fix → pass
7. **Export Brain** — Download + JSON preview

### Editing Checklist
- [ ] **Burn captions** — most Twitter videos are watched silent
- [ ] **Hook in 3 seconds** — first frame must be beautiful output
- [ ] **Show Director** — at least one scene proves Kimi/NVIDIA Director or local LM Studio Director usage
- [ ] **Show Script Studio** — one short prompt produces storyboard start frames and video jobs without manual page hopping
- [ ] **Show local model labels** — storyboard files or logs show `flux2_dev`, `flux2_klein`, or `z_image` prefixes
- [ ] **Arc is clear** — problem → solution → proof → takeaway
- [ ] **Under 60 seconds** — Twitter engagement drops after 60s
- [ ] **End with CTA** — logo + tagline, memorable

### Music Suggestions
- Upbeat, playful electronic for the hook
- Build to confident resolve for the payoff
- No lyrics — voiceover must be crystal clear
