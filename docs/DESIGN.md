# Visual Identity: Cinesmith Product Launch Video

## Style Prompt
Cinematic, professional, tech-forward, modern, sleek, intelligent, controlled, premium, agency-grade. The video should feel like a high-end production showcase with smooth animations, sophisticated typography, and a dark, atmospheric aesthetic that emphasizes the technological sophistication of the Cinesmith system.

## Colors

| Role | Hex | Usage |
|------|-----|-------|
| **Background** | `#050706` | Primary canvas background, sections, deep space |
| **Primary Accent** | `#35f0d0` (Teal) | Hermes brand, key highlights, active states, data flow |
| **Secondary Accent** | `#ffb45f` (Amber) | Kimi planning, critique highlights, warm elements |
| **Tertiary Accent** | `#90ffb5` (Green) | Memory, success states, compounding intelligence |
| **Text** | `#f3f8f6` (Off-white) | Main typography, headings, body text |
| **Muted Text** | `#9eb3ad` (Muted teal) | Secondary text, captions, subtle labels |
| **Line** | `rgba(183, 242, 229, 0.16)` | Subtle dividers, grid lines, structural elements |

## Typography

**Display & Body:** `Inter` - Clean, modern sans-serif that conveys technological sophistication while remaining highly readable. Used for all headings, body text, and UI elements.

**Code & Data:** `JetBrains Mono` - Precise monospace for terminal output, data streams, pipeline events, and technical annotations. Provides contrast and emphasizes the engineering rigor.

## What NOT to Do

1. **DO NOT** use bright, saturated primary colors (red, blue, yellow) - they clash with the sophisticated dark theme.
2. **DO NOT** use default system fonts (Arial, Times New Roman, Helvetica) - they undermine the premium feel.
3. **DO NOT** use jump cuts or abrupt transitions - every scene change must use smooth, purposeful transitions.
4. **DO NOT** overuse animations - keep motion purposeful and guided by the narrative.
5. **DO NOT** use placeholder text or lorem ipsum - all text must be meaningful and from the product documentation.
6. **DO NOT** use bright white backgrounds - maintain the dark, atmospheric aesthetic throughout.

## Motion Principles

- **Smooth & Controlled:** All animations should use eased motion (ease-out, cubic-bezier) with durations between 0.6-1.2s for scene transitions.
- **Data Flow Emphasis:** Use the primary teal (#35f0d0) to highlight data flow, pipeline events, and system intelligence.
- **Atmospheric Depth:** Use subtle parallax, atmospheric perspective, and layered compositions to create depth.
- **Typography-Driven:** Let typography guide the visual hierarchy with large, bold headings and clean, readable body text.

## Composition Rules

- **Hero Frame First:** Establish the core value proposition within the first 3 seconds.
- **Pipeline Visualization:** Use the canonical 6-step pipeline (Brief → Kimi → Skills → Compile → Audit → Memory) as a visual through-line.
- **Service Boundary Clarity:** Visually distinguish between Hermes (brain), Kimi (director), Skills (specialists), and Memory (provenance).
- **Data Provenance:** Show the data flow and event stream to emphasize transparency and control.
