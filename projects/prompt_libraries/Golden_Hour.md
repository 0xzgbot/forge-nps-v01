# Golden_Hour Prompt Pack

## Overview
The Golden Hour pack is designed to capture the perfect "emotional resonance" and "aesthetic peak" for brand content. It focuses on high-fidelity visual descriptions, lighting profiles, and atmospheric storytelling that elevates standard assets into premium, emotive experiences.

## Core Directives
1. **Atmospheric Precision**: Use specific terminology (e.g., cinematic LUTs, volumetric lighting, Rayleigh scattering) to define the mood.
2. **Emotional Anchoring**: Every prompt must include an emotional keyword (e.g., Nostalgic, Ethereal, High-Octane, Serene).
3. **Brand Consistency**: Ensure all visual descriptions align with the established brand lighting profiles and color palettes.

## Prompt Templates

### 1. The Cinematic Product Reveal
**Use Case**: Hero images for website landing pages or high-end social media ads.
**Prompt Structure**:
`[Subject: Detailed description of product] + [Environment: Contextual setting] + [Lighting: Golden hour/cinematic/studio] + [Camera: Lens type, angle, depth of field] + [Mood: Specific emotional anchor] --ar 16:9 --v 6.0`

### 2. The Lifestyle Narrative
**Use Case**: Creating authentic-feeling user-generated content (UGC) that feels "expensive."
**Prompt Structure**:
`[Persona: Character description] + [Action: Natural, unposed interaction with product] + [Setting: Relatable yet aspirational environment] + [Lighting: Soft natural light/dappled sunlight] + [Camera: Handheld feel, slight motion blur, shallow DOF] --ar 4:5`

### 3. The Abstract Texture Study
**Use Case**: Backgrounds, social media textures, or macro-detail shots for luxury branding.
**Prompt Structure**:
`[Macro Subject: Close-up of material/product detail] + [Lighting: Harsh side-lighting to emphasize texture] + [Color Palette: Brand colors applied] + [Atmosphere: Minimalist, clean, high-contrast] --ar 1:1`

## Implementation Notes
- **For Image Agents**: Combine these with the `visual_identity/material_specs` from the Brand Vault.
- **For Video Agents**: Use the "Cinematic Rhythm" protocols to match the lighting intensity to the edit pace.
