# Viral_Hook Prompt Pack

## Overview
The Viral_Hook pack is engineered to maximize "Stopping Power" and "Engagement Loops." It leverages psychological triggers identified in Q1 2026 research—specifically the shift towards AI-driven personalization and high-trust, low-friction interaction.

## Core Directives
1. **Immediate Cognitive Dissonance**: Start with a hook that challenges an assumption or presents a visually startling contrast.
2. **The "Co-Creator" Loop**: Design prompts that invite user input (text/image/voice) to create a personalized outcome.
3. **Frictionless Transformation**: Focus on the "Magic Moment"—the instant where simple input turns into high-value output.

## Prompt Templates

### 1. The Pattern Interrupt (Video/Social)
**Use Case**: Short-form video hooks (TikTok/Reels/Shorts).
**Prompt Structure**:
`[Visual Hook: Sudden change in scale, color, or motion] + [Text Overlay: Controversial or curiosity-inducing question] + [Audio Trigger: High-energy sync point] + [Pacing: Fast-cut transition to reveal]`

### 2. The Personalization Engine (Interactive)
**Use Case**: AI-powered interactive campaigns (e.g., "Your Brand, Remixed").
**Prompt Structure**:
`[Input Type: e.g., User's photo/voice note] + [Transformation Protocol: How the AI alters the input to fit brand aesthetic] + [Output Goal: A shareable, high-status version of the user's input] + [Call to Action (CTA): "Upload yours now"]`

### 3. The "Citation Bait" (Text/SEO)
**Use Case**: Creating content designed to be picked up by AI Search Summaries (GEO).
**Prompt Structure**:
`[Core Insight: A unique, data-backed perspective on [Topic]] + [Structure: Clear headings, bulleted lists, and authoritative tone] + [Context: Relatable real-world examples that provide "human" nuance]`

## Implementation Notes
- **For Marketing Strategist Agents**: Use these to build content calendars that balance "Reach" (Pattern Interrupt) with "Depth" (Citation Bait).
- **For Engagement Metrics**: Monitor the "Transformation Rate"—how many users complete the interaction loop.
